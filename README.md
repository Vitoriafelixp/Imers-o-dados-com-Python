# Dashboard de Salários na Área de Dados

Dashboard interativo para explorar e visualizar salários na área de tecnologia, desenvolvido durante a **Imersão Dados com Python da Alura**.

## Sobre o projeto

Durante a imersão, aprendi a tratar, analisar e visualizar dados com Pandas, Plotly, Seaborn, Matplotlib e Streamlit. No projeto final, usei esses aprendizados para construir um dashboard que permite explorar os dados de forma intuitiva e obter insights sobre salários na área de dados ao redor do mundo.

## Funcionalidades

### Filtros interativos

- Ano
- Senioridade
- Tipo de contrato
- Tamanho da empresa

### Métricas principais

- Salário médio
- Salário máximo
- Total de registros filtrados
- Cargo mais frequente

### Visualizações

| Gráfico | O que mostra |
|:--|:--|
| Top 10 cargos | Os cargos com maiores salários médios |
| Distribuição salarial | Como os salários se distribuem nos dados filtrados |
| Modalidades de trabalho | Proporção entre presencial, remoto e híbrido |
| Mapa interativo | Salário médio de Cientistas de Dados por país |

## Tecnologias utilizadas

- Python
- Pandas
- Plotly
- Streamlit
## Resultado

Com o dashboard, é possível filtrar os dados e acompanhar, em tempo real, como os salários variam por cargo, senioridade, país e modelo de trabalho.
